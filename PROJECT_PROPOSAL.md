**Short Description:**
We will analyse the MovieLens dataset (about 100,000 ratings of 9,700 movies by 610 users, scalable to
25 million ratings) on a 3-node cluster with one master PC and two worker PCs. The data will be stored in HDFS. A Hadoop
MapReduce job (Python, Hadoop Streaming) will compute the average rating per genre, and an Apache Spark
job running on YARN will compute the same result plus further insights: rating distribution, ratings per year,
average rating by release decade, top-rated and most-rated movies, and most active users. The MapReduce
and Spark outputs will be compared to verify correctness. Results will be shown on a web dashboard
(HTML/JavaScript with Chart.js) hosted on GitHub Pages. All code will be submitted through a GitHub repository.

**Components:** Hadoop (HDFS, YARN, MapReduce), Apache Spark (PySpark), Web UI (HTML/JS)
